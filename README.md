# 🍽️ FreshPlate – Smart Indian Meal Planner

FreshPlate is a smart and user-friendly Indian meal planning website designed to help users plan healthy and delicious meals.

## 🌱 Features

- 🍛 Indian meal planning
- 🥗 Healthy recipe suggestions
- 🛒 Grocery list generation
- 💧 Water intake tracker
- 🧮 Meal/calorie calculator
- 📱 Responsive design for mobile and desktop
- 🌙 Dark mode support
- 🎨 Attractive and modern user interface

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash Images
